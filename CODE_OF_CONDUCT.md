# Código de conducta

Este proyecto sigue el [Contributor Covenant](https://www.contributor-covenant.org) versión 2.1.

## Nuestro compromiso

Nos comprometemos a hacer de la participación en NLC una experiencia libre de acoso para todo el mundo, con independencia de edad, discapacidad, origen étnico, identidad o expresión de género, nivel de experiencia, educación, estatus socioeconómico, nacionalidad, apariencia, raza, casta, color, religión u orientación sexual.

## Normas

Ejemplos de comportamiento que contribuyen a un ambiente positivo:

- Mostrar empatía y amabilidad
- Respetar opiniones, puntos de vista y experiencias distintas
- Dar y aceptar crítica constructiva
- Centrarse en lo que es mejor para la comunidad
- Asumir responsabilidad y disculparse si se comete un error

Ejemplos de comportamiento inaceptable:

- Uso de lenguaje o imágenes sexualizadas
- Trolling, insultos o comentarios despectivos
- Acoso público o privado
- Publicar información privada de otras personas sin permiso
- Cualquier otra conducta que pueda considerarse inapropiada en un entorno profesional

## Aplicación

Los incumplimientos se pueden reportar a [@JuanCarlosGP](https://github.com/JuanCarlosGP) o mediante un [aviso de seguridad privado](https://github.com/JuanCarlosGP/NLC/security/advisories/new). Todas las denuncias se revisarán con discreción.

Quien no cumpla este código puede recibir una advertencia, o verse restringido o expulsado de los espacios del proyecto.

## Atribución

Este Código de Conducta es una adaptación de [Contributor Covenant](https://www.contributor-covenant.org), versión 2.1.
